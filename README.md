> **แพลตฟอร์มหาเพื่อนร่วมตี้หารค่าบริการและสินค้า – รวมกลุ่มกันหาร ประหยัดเงิน ปลอดภัย ใช้งานง่าย**

## 📌 ภาพรวมของโปรเจกต์ (Project Overview)

**HaanDaiBor (หารได้บ่)** คือ เว็บแอปพลิเคชันที่สร้างขึ้นมาเพื่อแก้ปัญหาสำหรับคนที่อยากใช้บริการสตรีมมิ่ง (เช่น Netflix, Spotify, YouTube Premium), ซื้อเกมแบบครอบครัว, สั่งอาหาร, หรือซื้อสินค้าต่างๆ ที่มีโปรโมชันเหมาจ่าย แต่ไม่มีเพื่อนหรือคนรู้จักมาร่วมแชร์ค่าใช้จ่าย

ระบบนี้จะทำหน้าที่เป็น **"สื่อกลางในการจับคู่คนหาร"** ที่ช่วยให้ทุกคนสามารถ:
- สร้างห้อง/โพสต์หาเพื่อนมาร่วมแชร์ค่าใช้จ่าย
- คำนวณราคาเฉลี่ยต่อคนให้อัตโนมัติ ป้องกันการคิดเลขผิด
- มีระบบคัดกรองสมาชิกเข้าห้อง (เจ้าของตี้ต้องกดอนุมัติก่อน)
- แชทพูดคุย ส่งสลิปโอนเงิน และสร้าง QR Code พร้อมเพย์ตามยอดหารได้ทันทีในหน้าเว็บ
- มีระบบโปรไฟล์ ตรวจสอบประวัติ และระบบรายงานผู้ใช้ เพื่อป้องกันมิจฉาชีพ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Backend (ระบบหลังบ้าน):** Python 3, Django (เวอร์ชัน 5.x)
- **Frontend (หน้าตาเว็บไซต์):** HTML5, Tailwind CSS, JavaScript (ผ่าน `django-tailwind` & `crispy-tailwind`)
- **Database (ฐานข้อมูล):** PostgreSQL (หรือ SQLite สำหรับเครื่องที่ไม่มี Postgres)
- **Authentication:** Django Allauth (รองรับ Google Login)
- **Payment Helper:** ไลบรารี PromptPay QR Code generator
- **Storage:** Cloudinary / Local Media รองรับการเก็บไฟล์รูปภาพ

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

ทำตามขั้นตอนด้านล่างนี้ทีละขั้นเพื่อเปิดใช้งานเว็บไซต์:

### ขั้นตอนที่ 1: ดาวน์โหลดโปรเจกต์และเข้าสู่โฟลเดอร์
เปิด Terminal (Mac/Linux) หรือ PowerShell / Command Prompt (Windows) แล้วพิมพ์:
```bash
git clone https://github.com/rachtachar/Haandaibor.git
cd HaanDaiBor
```

### ขั้นตอนที่ 2: สร้างและเปิดใช้งาน Virtual Environment (พื้นที่ติดตั้งโปรแกรมจำลอง)
เพื่อป้องกันไม่ให้แพ็กเกจของโปรเจกต์ไปปนกับโปรแกรมอื่นๆ ในเครื่อง:

- **บน Windows:**
  ```powershell
  python -m venv env
  .\env\Scripts\activate
  ```
- **บน macOS / Linux:**
  ```bash
  python3 -m venv env
  source env/bin/activate
  ```
*(เมื่อเปิดใช้งานแล้ว จะมีคำว่า `(env)` นำหน้าบรรทัดคำสั่ง)*

### ขั้นตอนที่ 3: ติดตั้งแพ็กเกจ Python ที่จำเป็น
```bash
pip install -r requirements.txt
```

### ขั้นตอนที่ 4: ติดตั้ง Tailwind CSS (สำหรับหน้าตาเว็บไซต์)
```bash
python manage.py tailwind install
```

### ขั้นตอนที่ 5: ตั้งค่าและสร้างฐานข้อมูล (Database Migration)
1. ตรวจสอบไฟล์ `config/settings.py` ในส่วนของ `DATABASES` ให้ตรงกับ PostgreSQL ในเครื่องคุณ (ค่าเริ่มต้นคือ database ชื่อ `haandaibor`, user `postgres`, password `1234`)
   > 💡 *หากยังไม่มี PostgreSQL สามารถปรับ `DATABASES` ชั่วคราวให้เป็น SQLite เพื่อทดสอบได้*
2. สั่งสร้างตารางข้อมูล:
```bash
python manage.py migrate
```

### ขั้นตอนที่ 6: สร้างบัญชีผู้ดูแลระบบ (Admin Superuser)
ใช้สำหรับเข้าจัดการหลังบ้าน (เช่น จัดการสมาชิก, อนุมัติการแบน, ดูรายงานปัญหา):
```bash
python manage.py createsuperuser
```
*(ระบบจะให้กรอก Username, Email และ Password ตามต้องการ)*

### ขั้นตอนที่ 7: (ทางเลือก) โหลดข้อมูลตัวอย่างสำหรับทดสอบ (Mock Data)
หากต้องการให้มีข้อมูลโพสต์และผู้ใช้งานจำลองในระบบทันที โดยไม่ต้องกดสร้างเองตั้งแต่ต้น:
```bash
python manage.py runscript load_mock_data
```
*(รหัสผ่านของ User จำลองทั้งหมดคือ `1234`)*

## ▶️ วิธีการรันระบบ (Running the Project)

สำหรับการพัฒนาบนเครื่อง จะต้องรัน **2 ส่วน** ควบคู่กัน (เพื่อให้อัปเดตทั้งเว็บและดีไซน์ CSS):

### แบบที่ 1: รันแยก 2 หน้าต่าง Terminal (แนะนำ)

- **หน้าต่างที่ 1: รันเซิร์ฟเวอร์เว็บไซต์ Django**
  ```bash
  # อย่าลืม activate env ก่อน
  python manage.py runserver
  ```

- **หน้าต่างที่ 2: รันตัวอัปเดตสไตล์ Tailwind CSS**
  ```bash
  # อย่าลืม activate env ก่อน
  python manage.py tailwind start
  ```

### แบบที่ 2: รันผ่านคำสั่งเดียวด้วย Honcho (ถ้าติดตั้งไว้)
```bash
honcho start -f Procfile.tailwind
```

## ❓ คำถามที่พบบ่อย (Troubleshooting & FAQ)

1. **ปัญหา: หน้ารันเว็บขึ้นว่าฐานข้อมูลเชื่อมต่อไม่ได้ (OperationalError / Connection refused)**
   - ตรวจสอบว่าเปิดโปรแกรม PostgreSQL Service ในเครื่องแล้วหรือยัง
   - ตรวจสอบชื่อฐานข้อมูล, User และ Password ในไฟล์ `config/settings.py` บรรทัดที่ 134-140

2. **ปัญหา: หน้าตารูปร่างเว็บไซต์เพี้ยน หรือสีไม่ขึ้น**
   - สาเหตุส่วนใหญ่เกิดจากไม่ได้เปิดคำสั่ง `python manage.py tailwind start` ให้ลองเปิดรันตัว Tailwind ควบคู่ไปด้วยเสมอ

3. **ปัญหา: เข้าสู่ระบบด้วย Google ไม่ได้บนเครื่องตัวเอง**
   - การล็อกอินด้วย Google จำเป็นต้องมี Client ID และ Secret จาก Google Cloud Console และตั้งค่า Authorized Redirect URI ให้ถูกต้อง
   - หากทดสอบเบื้องต้น แนะนำให้สมัครสมาชิกและล็อกอินด้วย Username / Password ตามปกติ
